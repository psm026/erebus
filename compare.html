EREBUS // sky check

Decoded twice, decoded once

Left: each room's sky as it renders now. The picture's colours get converted twice, so it comes out darker and harsher than it was made. Right: the same picture converted once, as made.

Both sides use the room's own opacity, gain, background colour and the site's tone mapping. Stars, fog, bloom and grain are left out so only the colour differs. To see it inside a room, add ?sky=split to the address, for example /?sky=split#w=hifi-temple.
